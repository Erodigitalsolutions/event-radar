# Getting started — the easy way

**You do not need:** git, a terminal, admin rights, or to install anything yourself. Works on company computers.
**You need:** Claude with the **Code** tab (the Claude desktop app has it).

## 3 steps
1. Open Claude and go to the **Code** tab.
2. Copy this whole message, paste it, press Enter. When Claude asks permission, click **Allow**:

   > Please install the Event Radar skill for me. Download https://github.com/Erodigitalsolutions/event-radar/raw/main/dist/event-radar-skill.zip and unzip it into my Claude skills folder (.claude/skills in my user folder) so that .claude/skills/event-radar/SKILL.md exists. Do not install anything else. Tell me when it is done.

3. Close Claude and open it again. Type: **set up my Event Radar**

That's it. It asks you some questions (about 10 minutes) and then you type **find events**.

## If something goes wrong
- **"Download blocked" / Claude can't download:** click this link in your web browser: https://github.com/Erodigitalsolutions/event-radar/raw/main/dist/event-radar-skill.zip — it saves a file in your Downloads folder. Then tell Claude: *"Install the Event Radar zip from my Downloads folder the same way."*
- **It says it needs a small program (Node):** say yes if it offers to install it. If your computer doesn't allow it, say *"work without installing anything"* — it uses a slower manual mode.
- **Anything else:** tell Claude what you see on screen. It checks your setup and helps.

## Good to know
- Your data stays in a folder on your computer (`.event-radar` in your user folder). Nothing is shared.
- It never pays or registers you for anything: it gives you the link, price and deadline.
- Money is only a hint: expensive events still show up, you decide.
- Reminders and the spreadsheet need Google Calendar / Drive connected in Claude. Without them you get files to open in Excel and a calendar file to import.
- To update to a newer version, paste the same message again.

# Para empezar — la forma fácil

**No necesitas:** git, terminal, permisos de administrador ni instalar nada tú. Funciona en computadores de empresa.
**Sí necesitas:** Claude con la pestaña **Code** (la app de escritorio la trae).

## 3 pasos
1. Abre Claude y entra a la pestaña **Code**.
2. Copia este mensaje completo, pégalo y pulsa Enter. Cuando Claude pida permiso, pulsa **Permitir**:

   > Instálame el skill Event Radar. Descarga https://github.com/Erodigitalsolutions/event-radar/raw/main/dist/event-radar-skill.zip y descomprímelo en mi carpeta de skills de Claude (.claude/skills dentro de mi carpeta de usuario) para que exista .claude/skills/event-radar/SKILL.md. No instales nada más. Avísame cuando termines.

3. Cierra Claude y ábrelo de nuevo. Escribe: **configura mi Event Radar**

Listo. Te hace unas preguntas (unos 10 minutos) y luego escribes **busca eventos**.

## Si algo falla
- **"Descarga bloqueada" / Claude no puede descargar:** haz clic en este enlace en tu navegador: https://github.com/Erodigitalsolutions/event-radar/raw/main/dist/event-radar-skill.zip — guarda un archivo en tu carpeta Descargas. Luego dile a Claude: *"Instala el zip de Event Radar desde mi carpeta Descargas, igual que antes."*
- **Dice que necesita un programa pequeño (Node):** di que sí si se ofrece a instalarlo. Si tu computador no lo permite, di *"trabaja sin instalar nada"*: usa un modo manual, más lento.
- **Cualquier otra cosa:** cuéntale a Claude lo que ves en pantalla. Revisa tu configuración y te ayuda.

## Conviene saber
- Tus datos quedan en una carpeta de tu computador (`.event-radar` dentro de tu carpeta de usuario). No se comparten.
- Nunca paga ni te inscribe: te da el enlace, el precio y la fecha límite.
- El dinero es solo una pista: los eventos caros también aparecen, tú decides.
- Recordatorios y hoja de cálculo requieren conectar Google Calendar y Drive en Claude. Sin eso recibes archivos para abrir en Excel y un archivo de calendario para importar.
- Para actualizar a una versión nueva, pega el mismo mensaje otra vez.
